# ICT_PEDAGOGY.md

Pedagogical documentation for **Information and Communication Technology in Primary Education**, an English-medium compulsory course in the Bachelor's Degree in Primary Education (Trilingual), Faculty of Education — Bilbao, University of the Basque Country (EHU).

**Current edition:** 2026–2027.

## Start here

- [PEDAGOGY.md](PEDAGOGY.md) — central course specification (v1.0): competences, learning outcomes, pedagogical principles, instructional design, content, assessment, feedback, AI use and maintenance.
- [Focused review and implementation actions](PEDAGOGY.md#183-focused-review-and-implementation-actions) — matters requiring teaching-team discussion or institutional alignment.

## Documentation approach

This repository implements the [PEDAGOGY.md standard](https://github.com/arceander/PEDAGOGY.md). The core file provides a stable pedagogical reference; selected complementary modules will be added progressively when they serve a defined purpose. Annual schedules, activities and tools may evolve without changing the core design. Documentation and student-facing materials are maintained in English.

The current specification is the initial repository baseline approved by the course teacher. Open review actions remain explicit. The official course guide and applicable institutional regulations govern formal course requirements; eGela remains the operational learning environment.

Do not publish identifiable student work, grades or other personal data in this repository.
